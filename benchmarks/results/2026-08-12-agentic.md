# Empirical Token Tax Benchmark Report

**Date**: 2026-08-12  
**Test Bed**: Monorepo benchmark suite evaluating Thai 🇹🇭 vs. Canonical English 🇺🇸 prompts across 5 major LLM tokenizers.

---

## Executive Summary

Non-English native developers using AI coding agents suffer from a severe **Token Tax** due to BPE tokenizer inefficiencies. On open-weights models like DeepSeek V3 and Qwen 2.5 Coder, Thai prompts consume **2.5× to 3.4× more tokens** than English equivalent prompts.

OpenNative eliminates this overhead completely by translating native prompts to Canonical English locally or via agent skill rules.
